# Bundled typography

Unmodified IBM Plex fonts, licensed under SIL Open Font License 1.1.
Source: https://github.com/IBM/plex (IBM official npm packages).

- IBM Plex Sans: `@ibm/plex-sans` 1.1.0, Regular / Medium / SemiBold.
- IBM Plex Mono: `@ibm/plex-mono` 2.5.0, Regular.

Full WOFF2 character sets are bundled. Font files are served from the application; no third-party font requests are made.
The adjacent license files retain the required copyright and reserved-name notices.
